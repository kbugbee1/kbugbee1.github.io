# Working drafts

Keep unfinished articles here as Markdown files such as `short-title.md`, copied
from one of the files in `_templates/`. Keep `published: false` while drafting.

**This is a public repository. Drafts committed here are public, even though
Jekyll excludes `_drafts` from normal site builds.** Anyone can read the files
and their Git history. Deleting a file later does not make its history private.
Keep confidential, restricted, personal, or otherwise nonpublic material outside
this repository. Only put material here that is already safe to share publicly.

Normal builds do not publish drafts. Private local previews can explicitly opt
in to showing them; see [the writing workflow](../WRITING_WORKFLOW.md) for the
review, preview, and publication steps. Do not commit generated preview output.

This README is documentation, not an article, and is excluded from site builds.
